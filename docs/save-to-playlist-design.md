# 動画を「tuitube」プレイリストに保存する(#12)

YouTube の「後で見る」には API から足せない(`playlistItems.insert` が `400 playlistOperationUnsupported` を返す。#68 で確認)。代わりに自分のアカウントに「tuitube」という非公開のプレイリストを用意し、そこへ足す。保存した動画はプレイリスト一覧(#69)から開ける。

## 操作

- 再生画面で `a` キーを押すか、アクション行の「★保存」を押す
- 結果一覧・チャンネル・プレイリストの中身では、選んでいる動画を `a` キーで保存する。検索欄では `a` は今までどおり文字として入る
- アクション行は「♥いいね」「＋登録」の右に「★保存」を並べる。この起動中に保存した動画(保存済みと分かった動画を含む)では色を付ける。起動し直すと灰色に戻る(保存済みかどうかを問い合わせないため)
- 再生画面の案内に「★a:保存」、一覧の案内に「a:保存」を足す。一覧の案内は 80 桁に収まらないので末尾に置き、幅のある端末でだけ出る
- 対象の動画 ID が無いとき(再生中の ID が無い・一覧が空)は何もしない(`l` と同じ)

## 保存の流れ

いいね/登録と同じ OAuth を使う。スコープは今の `youtube.force-ssl` のままで足りる。認証がまだなら、ブラウザでの認可から始まる。

1. `playlists.list?part=snippet&mine=true&maxResults=50` を `nextPageToken` で辿り、タイトルがちょうど「tuitube」のものを探す
2. 無ければ `playlists.insert?part=snippet,status` で作る(タイトル「tuitube」、公開設定 `private`)
3. `playlistItems.list?part=id&playlistId=…&videoId=…` で既に入っているかを見る。入っていれば足さずに「既に tuitube に保存しています」を出す。2 で作ったばかりのときは空なので見ない(作った直後に問い合わせると、プレイリストが見つからないと返る)
4. `playlistItems.insert?part=snippet` で足し、「tuitube に保存しました」を出す

API の割り当て(クォータ)は 1 回の保存で 52(作るときは 102)。1 日の既定の枠 10,000 に対して小さい。

送信中は「tuitube に保存中…」を出し、終わったら期限つきの知らせに置き換える。失敗はエラー行に出す。

## テスト

- `oauth`: 一覧から見つける/次のページで見つける/無ければ作る/入っていれば足さない/足す。各リクエストの URL・メソッド・本文・トークンの渡し方。失敗したときの文言
- 再生画面: `a` キーとクリックで保存が始まる/動画 ID が無ければ何もしない/送信中の知らせ/保存できたら色が付く
- 一覧: 結果一覧・チャンネル・プレイリストの中身で選んでいる動画が保存される/一覧が空なら何もしない/検索欄では文字として入る
- アクション行と案内の並び(80 桁で主なキーが落ちないこと)

## 対象外

- 起動をまたいだ保存済みの印と、サムネイルの印
