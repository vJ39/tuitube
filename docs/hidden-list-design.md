# 動画/チャンネルのローカル非表示

YouTube側には何も送信せず、tuitube側だけで指定した動画/チャンネルを以後の検索・フィード・チャンネル一覧結果から除外する。

## 保存先

`~/.config/tuitube/hidden.toml`(設定ファイルとは別のファイル。`config.toml`は`render()`で丸ごと書き直す設計のため、増減する非表示リストを同居させない)。

```toml
[[videos]]
id = "..."
title = "..."   # 見返す用。動作には使わない

[[channels]]
id = "..."
title = "..."
```

`$XDG_CONFIG_HOME/tuitube/`(未設定時`~/.config/tuitube/`)に置く。既存の`settings.rs`の`config_path`と同じ決め方に揃える。

## 操作

- Resultsモードで`h`キー: 選択中の動画を非表示リストに追加する
- Channelモードで`h`キー: 表示中のチャンネルを非表示リストに追加し、Resultsへ戻る(自チャンネルの動画は全部隠れるので見るものが無くなるため)
- 追加時は`set_temporary_notice`で「この動画を非表示にしました」/「このチャンネルを非表示にしました」を表示
- 一覧を見る画面が無いので、Results/Channelのフッタに`h:隠す`を出す

## フィルタ

`App::set_results`(結果一覧を差し替える唯一の経路)で、非表示リストに含まれる`id`(動画)/`channel_id`(チャンネル)の項目を除外してから格納する。既存の検索・フィード・チャンネル一覧のいずれの経路も`set_results`を通るため、フィルタ箇所は1箇所で足りる。

検索・フィード・チャンネル一覧はいずれも`--flat-playlist`で取るため、`channel_id`が入るのは検索結果だけになる。`channel_id`で照合できない行は、非表示チャンネルの名前(`[[channels]]`の`title`)と行の`uploader`が一致するかで判定する。同名の別チャンネルも外れうるが、隠したチャンネルの動画がフィードに残るより実害が小さい。

非表示にした直後は、現在表示中の一覧からも即座に取り除く(次の検索を待たない)。このとき選択位置は動画IDで引き直し、表示開始位置は選択位置より後ろにしない。最後の1件を隠して0件になった場合は検索欄へ戻す(チャンネル一覧では戻り先があるのでその場に留まる)。

## 読み込み

起動時に`hidden.toml`を読み込み、`App`に非表示IDの集合(`HashSet<String>`)として保持する。ファイルが無い/壊れている場合は空集合として起動する(既存の`config.toml`のfallbackパターンと同様、起動は止めない)。

## 書き込み

1件追加するたびに、現在のファイルを読み直してから末尾へ`[[videos]]`/`[[channels]]`を1つ足す。全文を書き直さないので、手で書いたコメントや未知のキーはそのまま残る。

読み直した内容がTOMLとして読めない場合は書かずにエラーを出す。解除は手編集なので打ち間違いは起こりうるが、空と見なして書き直すと既存の非表示分が消える。

書き込みは一時ファイルへ書いて`rename`で置き換える。一時ファイル名にはプロセスIDを入れ、同時に起動した別のtuitubeの書きかけを取り違えないようにする。`rename`の前に`sync_all`でディスクへ書き出す。

## 対象外(v1)

- 非表示リストの一覧表示・解除UI(手動で`hidden.toml`を編集すれば解除できる)
- 非表示件数の上限
