# 動画・プレイリストの URL を検索欄に入れて開く(#11)

検索欄に YouTube の URL を貼って Enter を押すと、検索せずにその中身を開く。

- 動画の URL: その動画を 1 件だけの一覧にして、そのまま再生を始める。再生を終えると、その 1 件の一覧へ戻る(もう一度再生する・ダウンロードする・保存するなど、一覧の操作がそのまま使える)
- プレイリストの URL: そのプレイリストの動画一覧を開く(プレイリスト一覧から開いたときと同じ画面)。Esc で検索側へ戻る

## 受け付ける URL

`https://` は無くてもよい。ホストは `youtube.com`(`www.`・`m.`・`music.` 付きも)と `youtu.be`。

- 動画(動画 ID は 11 文字の英数字・`-`・`_`)
  - `youtube.com/watch?v=ID`。`&t=`・`&list=` などが付いていても動画として扱い、ID だけを使う
  - `youtu.be/ID`
  - `youtube.com/shorts/ID`・`youtube.com/live/ID`・`youtube.com/embed/ID`
- プレイリスト: `youtube.com/playlist?list=ID`(ID は英数字・`-`・`_`)

これ以外(チャンネルの URL、他のサイト、ID の形が違うもの)は今までどおり検索語として扱う。

## 動画の URL の流れ

1. 検索欄で Enter を押したとき、検索語が動画の URL なら `Target::Video(ID)` を取りに行く。yt-dlp には `https://www.youtube.com/watch?v=ID` を渡す(検索と同じ引数。cookie も同じく渡す)
2. yt-dlp は動画 1 本の情報を 1 行で返す(実測)。この行には検索結果の行と違って `ie_key` が無いので、検索用の「動画の行だけを残す」絞り込みは掛けない
3. 届いたら一覧(「すべて」タブ)に 1 件として入れ、そのまま再生を始める。ただし、届くまでに設定画面などへ移っていたら始めない。取れなかったときは今の検索と同じくエラー行に理由を出す

タイトル・長さ・チャンネルは yt-dlp の情報から入るので、状態行の表示やアクション行の登録(＋登録)は普通の検索結果から再生したときと同じになる。

## プレイリストの URL の流れ

1. 検索欄で Enter を押したとき、検索語がプレイリストの URL なら、プレイリスト一覧から開くときと同じ手順でそのプレイリストの中身を取りに行き、動画一覧の画面へ移る
2. プレイリストの名前は、yt-dlp が各行に入れる `playlist_title` から入れる(実測)。届くまでは状態行に「プレイリスト」と出す
3. Esc・`/` で戻ると、プレイリスト一覧を開いていないので検索側(結果一覧か検索欄)へ戻る。プレイリスト一覧から開いたときは今までどおり一覧へ戻る

## 表示

検索欄の案内を「検索したい語句か動画・プレイリストの URL を入力して Enter」に変える。

## テスト

- URL の読み取り: 受け付ける各形、`&t=`・`&list=` の付いた動画の URL、`https://` 無し、別のサイト、ID の長さや文字が違うもの、ただの文字列
- 検索欄の Enter: 動画の URL なら `Target::Video` を取りに行き、yt-dlp に watch の URL を渡す。プレイリストの URL ならその中身を取りに行って動画一覧へ移る。どちらでもなければ今までどおり検索
- yt-dlp の出力の読み取り: `ie_key` の無い動画 1 本の行を 1 件として読む。プレイリストの行から名前を拾う
- 届いた後: プレイリストの名前が入る。再生を始めるかの判定は、`Target::Video` で 1 件届き、結果一覧にいるときだけ真。再生そのものは本物の mpv を起動するので単体テストでは動かさず、手元で実際に URL を入れて確かめる
- URL で開いたプレイリストから戻ると検索側へ戻る。プレイリスト一覧から開いたときは一覧へ戻る(今の振る舞い)

## 対象外

- URL の `t=`(再生開始位置)の反映
- チャンネルの URL を開くこと
